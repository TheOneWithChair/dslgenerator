NAME: Start
BLOCK_TYPE: start
MODE_AVAILABILITY: workflow, chat, agent-chat, advanced-chat
IS_SINGLETON: true
IS_START: true
OUTPUTS:
  - user-defined variables (each variable key becomes an output)
  - sys.query (string) — chat mode only
  - sys.files (array[file]) — all modes

REQUIRED_DATA_FIELDS:
  type: "start"
  title: string (display name)
  desc: string (can be empty)
  variables: InputVar[] (can be empty list)

VARIABLE_SCHEMA (InputVar):
  variable: string        # key name, must be unique in node
  label: string           # display label
  type: InputVarType      # see ENUM below
  required: boolean
  max_length: number      # optional, for text/paragraph
  default: string|number  # optional
  options: string[]       # required only when type=select
  placeholder: string     # optional
  allowed_file_types: ["image","document","audio","video","custom"]   # files only
  allowed_file_upload_methods: ["local_file","remote_url"]            # files only
  allowed_file_extensions: [".pdf",".txt",".docx",...]               # files only
  number_limits: number   # max files, files only

  text-input    → single line text
  paragraph     → multi-line text
  select        → dropdown (requires options[])
  number        → numeric input
  url           → URL with validation
  file          → single file upload
  file-list     → multiple file upload
  json          → raw JSON
  checkbox      → boolean

REFERENCE_FORMAT:
  In template strings: {{#<node_id>.<variable_name>#}}
  In value_selector:   ["<node_id>", "<variable_name>"]

>>>EDGE_RULES_START

STANDARD_EDGE_FORMAT:
  id: "{source_node_id}-source-{target_node_id}-target"
  source: "{source_node_id}"
  sourceHandle: source
  target: "{target_node_id}"
  targetHandle: target
  type: custom
  data:
    sourceType: {source_block_type}    # e.g. "start", "llm", "code"
    targetType: {target_block_type}    # e.g. "llm", "end", "answer"
    isInIteration: false
    isInLoop: false
  zIndex: 0

IF_ELSE_EDGE_TRUE_BRANCH:
  id: "{ifelse_node_id}-true-{target_node_id}-target"
  source: "{ifelse_node_id}"
  sourceHandle: "true"               # NOT "source" — must be "true"
  target: "{target_node_id}"
  targetHandle: target
  type: custom
  data:
    sourceType: if-else
    targetType: {target_block_type}
    isInIteration: false
    isInLoop: false
  zIndex: 0

IF_ELSE_EDGE_FALSE_BRANCH:
  id: "{ifelse_node_id}-false-{target_node_id}-target"
  source: "{ifelse_node_id}"
  sourceHandle: "false"              # NOT "source" — must be "false"
  target: "{target_node_id}"
  targetHandle: target
  type: custom
  data:
    sourceType: if-else
    targetType: {target_block_type}
    isInIteration: false
    isInLoop: false
  zIndex: 0

ITERATION_INNER_EDGE:
  Same as STANDARD_EDGE_FORMAT but:
  data:
    isInIteration: true              # set true for edges INSIDE an iteration block
    isInLoop: false

RULES:
  1. Edge ID format MUST be: "{source_id}-source-{target_id}-target"
     Exception: if-else uses "{ifelse_id}-true-{target_id}-target" or "{ifelse_id}-false-{target_id}-target"
  2. Every node except End/Answer MUST have at least one outgoing edge
  3. Every node except Start MUST have at least one incoming edge
  4. zIndex is always 0
  5. type is always "custom"
  6. targetHandle is always "target"
  7. sourceHandle is "source" for all nodes EXCEPT if-else (which uses "true"/"false")

>>>EDGE_RULES_END

X_AXIS_SPACING:
  Start node:        x = 80
  Each subsequent column: x += 300
  So: col0=80, col1=380, col2=680, col3=980, col4=1280

Y_AXIS_RULES:
  Single linear flow:        y = 282 for all nodes
  Parallel branches (if-else true):   y = 100
  Parallel branches (if-else false):  y = 460
  Merge after branches:       y = 282
  Inner iteration nodes:      y = 282 (relative to iteration container)

POSITION_FORMULA:
  position:
    x: 80 + (column_index * 300)
    y: 282   # for linear flow

ITERATION_CONTAINER:
  The iteration node itself has a position
  Inner nodes positions are relative to the iteration container's origin
  Inner nodes: x starts at 80, y = 282

VIEWPORT:
  Always set:
    viewport:
      x: 0
      y: 0
      zoom: 0.7

>>>VALIDATION_RULES_START

STRUCTURAL_RULES:
  1. Every DSL must have exactly one Start node
  2. workflow mode: must have at least one End node, zero Answer nodes
  3. chat mode: must have at least one Answer node, zero End nodes
  4. Every non-terminal node must have at least one outgoing edge
  5. Every non-start node must have at least one incoming edge
  6. No orphan nodes (nodes with no edges at all)

REFERENCE_RULES:
  7. Every {{#node_id.key#}} — node_id must exist in nodes[]
  8. Every value_selector[0] must be a node_id that exists in nodes[]
  9. Every edge source and target must be node_ids that exist in nodes[]
  10. if-else edges must use sourceHandle "true" or "false", not "source"

FIELD_RULES:
  11. Every node must have: id, type=custom, sourcePosition, targetPosition, position, data.type, data.title, data.desc
  12. llm nodes must have: model.provider, model.name, model.mode, prompt_template (non-empty)
  13. end nodes must have: outputs[] (can be empty list)
  14. answer nodes must have: answer field (non-empty string)
  15. code nodes must have: code, code_language, outputs[]
  16. knowledge-retrieval nodes must have: dataset_ids[] (can be placeholder), query_variable_selector

ID_RULES:
  17. All node IDs must be unique
  18. Edge IDs must be unique
  19. Recommended ID format: UUID v4 (e.g. "a1b2c3d4-1a2b-4c3d-8e5f-1a2b3c4d5e6f")
  20. Start node ID is typically "start-node-uuid" style but any unique string works

>>>VALIDATION_RULES_END
